# Лабораторная работа №2
## Тема: Практическое применение. Работа с Git, репозиторием и командная разработка.

### Цель работы
Закрепить знание JavaScript на практической задаче. Отработать навыки работы с Git (pull, commit, push) в рамках командного репозитория. Научиться передавать наработки тимлиду.

---

## Ход работы

### Этап 1. Настройка репозитория
1. Все участники команды клонируют общий репозиторий, созданный преподавателем.
2. Тимлид (Макар) создает ветку `main` и ветку `develop`.
3. Каждый участник создает свою личную ветку от `develop` с названием `feature/имя_студента`.

### Этап 2. Разработка программы «Анализ успеваемости»
Необходимо написать скрипт, который обрабатывает массив оценок студентов. Данные жестко заданы в коде:

```javascript
const grades = [
    { name: "Макар", score: 85 },
    { name: "Денис", score: 92 },
    { name: "Анна", score: 78 },
    { name: "Даша", score: 88 },
    { name: "Студент_X", score: 45 }
];
```
